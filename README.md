# Portfolio

Portfolio personnel de Josselin Robin, construit avec React, TypeScript, Vite et Tailwind CSS.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS v4
- Lucide React

## Installation

```bash
npm install
npm run dev
```

L’application sera disponible sur l’URL indiquée par Vite, généralement `http://localhost:5173`.

## Commandes utiles

```bash
npm run dev       # serveur de développement
npm run build     # build de production
npm run preview   # prévisualiser le build
npm run lint      # vérifier le code
```

Sous PowerShell, utiliser `npm.cmd` si l’exécution de `npm.ps1` est bloquée.

## Structure

- `src/components/` : composants React réutilisables.
- `src/index.css` : tokens de couleurs et styles globaux.
- `public/` : fichiers statiques.
- `public/cv_josselin_robin.pdf` : CV téléchargé depuis la navbar.

Les conventions détaillées sont disponibles dans [AGENTS.md](./AGENTS.md).
